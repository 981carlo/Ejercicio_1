Proyecto de Backend con Python y fastAPI para conectar una base de datos de usuarios con la API de Spotify.

Para hacer uso de la API hay que introducir las credenciales de Spotify en las correspondientes variables (client_id y client_secret) del archivo ".env".

Disponemos de una base de datos en local (usuarios_spotify) con una tabla (usuarios) que cuenta con los campos: id, nombre, apellido, album_favorito y artista_favorito. Se ha implementado un CRUD en main.py para poder añadir, consultar, modificar y borrar usuarios de la base de datos. Se incluye un archivo ".sql" con una copia de la tabla y algunos usuarios como ejemplo en la carpeta /usuarios_spotify_DB. La función make_connection() del archivo main.py debe ser revisada a fin de pasar los valores necesarios de "user" y "password" para realizar la conexión con la base de datos local.

Atraves del endpoint "/add_album/:id/:q" accedemos al endpoint de búsqueda de la API de Spotify para encontrar nuestro album favorito. Nuestro endpoint recibe 2 paramatros. Con el primero, id, indicamos qué usuario de la base de datos está haciendo la consulta. En el segundo, q, escribimos el nombre de nuestro album favorito. Si lo encuentra, el programa introducirá el album favorito y el artista al que pertenece en los campos corespondientes del usuario pasado por parámetro con el id.
